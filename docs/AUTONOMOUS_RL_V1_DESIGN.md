# AUTONOMOUS-RL-RESEARCH-V1 设计与执行计划

用户本轮明确授权替代当前“未来研究预算0”的限制，但不修改任何历史授权记录。采用独立附加协议，不扩大OPS-V2维护任务能力、不重写L9R的denial、不自动续训。

## 固定授权

- 总量2,000,000 environment timesteps，累计训练墙钟86400秒，跨重启累计；单次最多1,000,064步。
- CPU、单worker；PPO/课程对照及经新协议审查的算法研究。PX4、FAST-LIO2、实机和封存Test运行不授权。
- 本版本先只实现PPO执行。未来监督训练需先明确样本/optimizer与总预算的折算，不从本版本产生免费监督更新。
- 独立授权文件及append-only预算事件位于`.research_local/authorized_rl_v1/`。先预留完整步数和墙钟上限，成功、失败或未知中断均不自动返还；额外记录主管实测墙钟，不以子进程自报时间退款。原始reservation永久保留。

## 三种方案与选择

不选改V2零预算常量（破坏历史身份）；不选裸调用旧训练脚本（无累计预算及停止审计）。选新增标准库预算/主管模块，复用既有MuJoCo环境、SB3 PPO、终止记账、失败记录、Checkpoint及Validation，不复制算法。

## 架构

`版本化用户grant → 共享flock/版本核验 → 独立预算reservation → 固定训练worker → 原PPO与环境 → checkpoint/Validation → 完整证据结算`。

训练worker不接收shell、任意脚本或checkpoint初始化路径。主管独立监测墙钟/内存/磁盘/停止请求，训练子进程单独进程组；主管丢失时worker主动停止。不确定attempt禁止重放；recover只报告，不自动运行。

## 第一项研究协议（执行前单独冻结）

先在冻结Train的三个empty身份各运行最多375步state-only Scripted、真实动力学，要求全部原成功标准通过，否则先离线诊断，不训练。

A全程均匀12Train；B前32768只均匀3empty，之后均匀12Train。各65536实际步，新初始化seed0、初始权重配对；PPO/CNN/Reward/物理/动作/24000射线不变。B只在32768之后**下一个自然episode reset**切换分布，不强制截断episode；A在同一rollout边界也执行相同保存/Validation。两组调度RNG独立且相同初始seed0，训练随机噪声由相同初始seed0配对，不声称两组采样状态永远相同。

每臂32768/65536完整optimizer之后保存checkpoint；训练结束并关闭Train的MuJoCo后，按两份冻结权重各执行6个Validation（避免两个物理实例常驻且不干扰训练RNG），再验证重载；Test=0。Final Checkpoint，不择优。每臂wall<=3600s，合计上限7200s计入86400。成功标准保持距离<.10m、速度<.15m/s、连续5步。主要比较6个Validation身份的成功数；课程优势预先要求末期成功数高于对照且碰撞数不增加；若两组均0成功，不判课程有效，继续根据新证据研究而非自动加预算。
