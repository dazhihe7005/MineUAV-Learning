# Reward V2 Low-Std Multi-Seed Validation Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline; this project is not a Git repository, so keep isolated artifacts in the existing project and do not create a worktree or commits.

**Goal:** Determine whether Reward V2 PPO with `log_std_init=-2.0` reliably learns waypoint stopping across five independent training seeds.

**Architecture:** Reuse the existing low-std PPO factory, callback, reward/environment and fixed evaluation. Permit the factory to accept a seed without changing its default. Reuse the completed seed 20260929 run and train seeds 0, 8, 16, 24 from scratch, each in separate artifact directories. SB3 seeds each of eight environments as `seed + rank`; spacing training seeds by eight avoids shared target RNG streams. Evaluate all five final models on identical fixed100 full targets and a disjoint, independently generated holdout100 full target set, then aggregate per-seed statistics.

**Tech Stack:** Python, NumPy, PyTorch, Stable-Baselines3 2.9.0, Gymnasium, MuJoCo, unittest.

**Spec:** Current user multi-seed robustness request.

## Global Constraints

- No change to Reward V2, observation, action, controller, timing, actor/critic [64,64], PPO hyperparameters or `log_std_init=-2.0`.
- `n_envs=8`, `n_steps=256`; each new seed stops at the full 100,352-transition rollout, never extends after failure.
- Training seeds: prior 20260929 plus fresh 0, 8, 16, 24. Separate model/log/TensorBoard/report paths for every new seed; preserve previous experiment artifacts. Exploratory 1/2/3 runs were interrupted after review found rank-seed overlap; retain their partial files but exclude them from five-seed statistics.
- Fixed benchmark: seeds 20261001–20261100, original 100 full targets. Holdout: seeds 20271001–20271100 generated by the unchanged full target sampler, not used for training or interim evaluation.
- All evaluation uses `deterministic=True` and existing near-target/crossing definitions. Record first threshold crossing only at evaluated 20k/50k/100k checkpoints, labeled as approximate checkpoint resolution.

## Review Focus

- Seed 0 must be treated as a valid explicit seed, not falsy/default.
- `PPO(seed)` must seed Python/NumPy/Torch/action space and all eight envs before first reset; no probe may consume a training env reset.
- Reused 20260929 report must not be silently treated as a freshly recorded initial RNG state.
- Every model must see the same fixed and holdout targets, with no holdout seed in interim training evaluations.
- A seed with zero successes must retain an undefined completion time, not report zero seconds.
