## Only objective change

Reuse the original v1 `predict_windows` and `predict_latent` unmodified. Encode
the real causal prefix through start t once, with gradient retained. From z[t],
perform 10 pure latent transitions with recorded actions. Do not feed future
observations, reference latents or decoded observations into T. No step detaches.

```
Lobs = mean_over_windows,k=0..10,7dims
       (D_norm(z_pred[t+k]) -
        (observation[t+k] - Train_observation_mean) / Train_observation_std)^2

z_ref[t+k] = E(real history through t+k)               # training target only
Lauto = mean_over_windows,k=1..10,64dims
        ((z_pred[t+k] - stopgrad(z_ref[t+k])) / sigma_initial_Train)^2

Ltotal = Lobs + 0.1 * Lauto
```

`D_norm` is the actual normalized decoder output; its physical readout is
`D_phys = Train_observation_mean + Train_observation_std * D_norm`.
Thus Lobs is equivalently `((D_phys - observation) / Train_observation_std)^2`.

There is **no v2 local consistency term**. The consistency predictions are the
exact autonomous states already generated by the observation path, not new local
predictions starting from real-history latents. A separate causal real-history
Encoder pass under `no_grad`, followed by explicit detach, supplies reference
targets. Reference k1..10 includes the saved episode terminal frame when needed.

The consistency gradient traverses all composed states and initial source E.
The entire reference branch receives no consistency gradient. D receives only
observation gradients, not direct consistency gradients. Future observations
are permitted as loss/reference targets, never as prediction inputs. Inference
contains no reference branch. Tests perturb reference targets, change Lauto,
and establish bit-identical predictions; deleted future inputs are also tested.

Use exactly v2's initial Encoder Train-only population std, floor1e-6, held fixed
throughout (no mean subtraction). Its range is .145670–.256167 from147219frames.
The existing initial-scale JSON is reused by byte/semantic hash rather than
duplicated. Runtime transition uses raw current latent coordinates; no old latent
statistics constrain its forward inputs.

Every minibatch measures weighted consistency gradients with `autograd.grad`,
then applies the unchanged total backward/Adam step. Observation gradients are
total minus weighted-consistency by linearity, subject to FP32 roundoff. Report
E/T/D norms and consistency/observation ratios; no rescaling based on diagnostics.
History keys `consistency` and `weighted_consistency` denote Lauto and .1Lauto,
not a local term. Online Train epoch means differ from fixed selected-model losses.

the autonomous composition trajectory is more effective for H25/H50 than the
tested local consistency objective, while reconstruction/variance stay healthy.

deterministic state-space models, not a unique root cause, statistically robust
multi-seed effect, or complete deployed World Model agent.

positive fixed experiment; v2 stays negative, v1 stays the historical
